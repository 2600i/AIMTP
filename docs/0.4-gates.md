# AIMTP 0.4 Gate And Default Matrix

> **Status: NEEDS_UPDATE.** This matrix remains useful for the experimental
> 0.4-gated surfaces, but its RC framing and every runtime/reserved variable
> must be re-audited before it is treated as current operator guidance.

This was the authoritative 0.4 gate/default audit for RC prep.
Each 0.4 gate appears exactly once in this table.

| Env var | Allowed values | Default | Scope | Inert-by-default proof |
| --- | --- | --- | --- | --- |
| `INTENTOS_PROTOCOL_VERSION` | `0.4` (anything else disables 0.4 paths) | `unset` | runtime | With `unset`, all 0.4 loaders and handshake paths remain disabled/skipped. |
| `INTENTOS_FEDERATION` | `on`, `off` | `off` | runtime | With `off`, federation handshake paths are inactive. |
| `INTENTOS_IDENTITY` | `on`, `off` | `off` | runtime | With `off`, identity-anchor exchange paths are inactive. |
| `INTENTOS_HANDSHAKE_PEER_VERIFY` | `off`, `warn`, `enforce` | `off` | runtime | With `off`, peer-proof checks are not required and baseline handshake behavior is preserved. |
| `INTENTOS_HANDSHAKE_NEGOTIATION` | `off`, `on` | `off` | runtime | With `off`, capability negotiation enforcement is inactive. |
| `INTENTOS_HANDSHAKE_SEND_ANCHORS` | `off`, `inline`, `setid` | `off` | tool-only | With `off`, handshake demo does not send anchor payloads. |
| `INTENTOS_HANDSHAKE_REVOCATION_CASE` | `off`, `peer`, `key`, `anchor` | `off` | tool-only | With `off`, handshake demos do not force a revocation scenario. |
| `INTENTOS_REVOCATIONS` | `off`, `on` | `off` | runtime | With `off`, revocation loading/enforcement paths are bypassed. |
| `INTENTOS_REVOCATION_POLICY` | `off`, `warn`, `enforce` | `off` | runtime | With `off`, revocation checks do not reject requests or tool flows. |
| `INTENTOS_REVOCATION_PROOF` | `off`, `on` | `off` | runtime | With `off`, revocation proof presence/validity is not enforced. |
| `INTENTOS_TRUST_DISTRIBUTION` | `off`, `fs`, `http` | `off` | runtime | With `off`, distribution adapters are inactive and loaders return skipped. |
| `INTENTOS_TRUST_BUNDLE` | `off`, `on` | `off` | runtime | With `off`, trust-bundle load/verify/apply paths remain inert. |
| `INTENTOS_TRUST_BUNDLE_POLICY` | `off`, `warn`, `enforce` | `off` | runtime | With `off`, bundle validation does not become a hard rejection path. |
| `INTENTOS_IDENTITY_POLICY` | `off`, `warn`, `enforce` | `off` | documented/reserved | Current runtime does not consume this variable; defaults remain inert. |
| `INTENTOS_IDENTITY_MAX_TIMESTAMP_SKEW_SEC` | non-negative integer seconds | `300` | documented/reserved | Current runtime does not consume this variable; defaults remain inert. |

Notes:
- Source-location env vars (paths/URLs/key maps) are configuration inputs, not gates.
- See `tests/0.4-defaults-inert.test.mjs` for default-inert coverage.
