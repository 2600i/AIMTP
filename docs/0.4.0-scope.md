# AIMTP 0.4.x Scope

## In Scope for 0.4.x
- Gated federation handshake.
- Identity anchors.
- Peer signature verification.
- Capability negotiation.

## Out of Scope for 0.4.x
- Revocation distribution.
- Multi-hop federation routing.
- On-chain anchoring.
- Automatic trust propagation.

## Stability Guarantees
- All new environment flags default to `off` (inert by default).
- No receipt format drift.
- No cryptographic semantic changes.
