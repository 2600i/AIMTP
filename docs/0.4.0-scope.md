# Historical: AIMTP 0.4.x Scope

> This was the planning boundary for the initial 0.4.x phase, not a current
> repository inventory. Revocation and multi-hop federation experiments were
> added later. See [`docs/0.4-gates.md`](0.4-gates.md) and
> [`docs/architecture.md`](architecture.md) for current boundaries.

## In Scope for 0.4.x
- Gated federation handshake.
- Identity anchors.
- Peer signature verification.
- Capability negotiation.

## Out of Scope for 0.4.x
- Revocation distribution.
- Multi-hop federation routing.
- On-chain anchoring.
- Automatic trust propagation.

## Stability Guarantees
- All new environment flags default to `off` (inert by default).
- No receipt format drift.
- No cryptographic semantic changes.
